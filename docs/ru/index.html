Бесплатная версия

Хотите сначала попробовать на своём компьютере?

Бесплатная версия — программа для Windows. Она закрывает основные задачи мастерской, но работает только на том компьютере, где вы её установили.

  • Работает на вашем компьютере, без абонентской платы
  • До 3 пользователей
  • Нет доступа с телефона и других устройств
  • Без WhatsApp, без ссылки для отслеживания и без N8N
⬇ Скачать бесплатно для Windows (85 МБ)

Windows 10 или 11 · устанавливается без пароля администратора · занимает несколько минут

Как установить

  1. Скачайте и сохраните BancadaSync-Setup.exe.
  2. Дважды щёлкните и следуйте мастеру установки. Если Windows покажет предупреждение, нажмите Подробнее, затем Выполнить в любом случае.
  3. Откройте BancadaSync и создайте свою мастерскую и пользователя.
Частые вопросы

Остались вопросы?

Нужно ли что-то устанавливать для онлайн-системы?

Нет. Просто войдите через браузер на компьютере, планшете или телефоне, указав e-mail и пароль.

Когда система открывается после оплаты?

Сразу после подтверждения оплаты. Вы создаёте аккаунт, подтверждаете e-mail и платите; доступ открывается автоматически.

Какой тариф выбрать?

«Начальный» подходит тем, кто только начинает: до 400 заказов в месяц, вы и 2 сотрудника. «Профессиональный» — для мастерских с командой и WhatsApp: до 600 заказов и 8 пользователей. В «Бизнесе» нет ограничений по заказам и пользователям.

Какие ограничения у бесплатной версии?

Она работает только на компьютере, где установлена, для до 3 пользователей, и не включает WhatsApp, ссылку для отслеживания и N8N.

Почему Windows показывает предупреждение при установке бесплатной версии?

У установщика пока нет платной цифровой подписи (сертификата «проверенного издателя»), поэтому SmartScreen показывает «неизвестный издатель». Файл тот же, что опубликован здесь; проверьте целостность по хешу ниже.

Где хранятся данные бесплатной версии?

На вашем компьютере, в %APPDATA%\CRM Assistencia. При удалении программа спрашивает, удалить ли данные; по умолчанию они сохраняются.

Как проверить, что файл бесплатной версии оригинальный? (SHA-256 версии 1.0.0)

1d10463c9d5ac24ce16623b04e5573c4cbf718de99053cb7d86f108681689fa7
В PowerShell: Get-FileHash .\BancadaSync-Setup.exe -Algorithm SHA256
